## 👑 : " ʜᴀᴢʙɪɴ ʜᴏᴛᴇʟ "
_________

🐏 : ɪɴᴛ ⟢ ꜱᴇʀᴀ x ᴄᴀʀᴍɪʟʟᴀ (ᴀɴɢᴇʟɪᴄʙᴀʟʟᴇᴛ), ᴄʜᴀɢɢɪ, ʀᴀᴅɪᴏꜱɪʟᴇɴᴄᴇ (ᴀʟꜱᴏ ꜱᴏᴍᴇᴡʜᴀᴛ ɪᴡᴄ?), ꜱᴛᴀᴛɪᴄᴍᴏᴛʜ, ʀᴀᴅɪᴏʀᴏꜱᴇ, ᴄʜᴀʀʟɪᴍʏ, ꜱɴᴀᴋᴇʙᴏᴍʙ, ᴠᴇʟᴍɪʟʟᴀ, ᴠᴇʟɪꜱꜱᴀ, ᴘᴏʟʏᴇᴅᴇɴ, ʀᴏꜱɪᴇ x ʟɪʟɪᴛʜ, ʀᴏꜱɪᴇ x ᴄᴀʀᴍɪʟʟᴀ, ʟᴜᴄɪʟɪʟɪᴛʜ, ꜱᴛᴀᴛɪᴄʙᴇʟʟᴇ, ᴄᴀɴɴɪʙᴀʟꜱʜᴀʀᴋ (ʀᴏꜱɪᴇ x ᴠᴏx), ᴇᴍɪʟᴜᴛᴇ, ꜱᴛᴀᴛɪᴄᴀᴘᴘʟᴇ, ᴢᴇꜱᴛᴍɪʟʟᴀ, ʜᴜꜱᴋᴇʀᴅᴜꜱᴛ, ʙᴀxꜱᴛᴀʙʙᴇʀ, ꜰᴀꜱʜɪᴏɴʙᴇʟʟᴇ, ᴍᴇᴅɪᴀʙᴇʟʟᴇ, ʀᴀᴅɪᴏʙᴇʟʟᴇ, ᴍᴏᴛʜʙᴇʟʟᴇ (ᴄʀᴀᴄᴋꜱʜɪᴘ), ᴍᴇᴅɪᴀᴍᴏᴛʜʙᴇʟʟᴇ (ᴄʀᴀᴄᴋꜱʜɪᴘ), ꜰᴀʟʟᴇɴᴡɪɴɢꜱ, ᴄʜᴀʀʟɪᴇꜱ ᴀɴɢᴇʟꜱ ( ᴇᴍɪʟʏ x ᴠᴀɢɢɪ x ᴄʜᴀʀʟɪᴇ), ᴄʜᴀʀʟᴜᴛᴇ, ᴄʜᴀʀʟɪᴇꜱ ᴇxᴏʀᴄɪꜱᴛꜱ ( ʟᴜᴛᴇ x ᴠᴀɢɢɪ x ᴄʜᴀʀʟɪᴇ ). ꜰᴀʟʟᴇɴᴅᴏʟʟ, ꜰᴀꜱʜɪᴏɴꜱᴘᴇᴀʀ, ᴇᴍɪʟᴇᴛᴛᴇ, ʀᴏꜱᴇᴍᴏᴛʜ (ʀᴏꜱɪᴇ x ᴠᴀʟ).

🌈 : ᴅɴɪ ⟢ ᴘᴏʟʏᴠᴇᴇꜱ, ᴠᴀʟᴀɴɢᴇʟ, ʀᴀᴅɪᴏꜱᴛᴀᴛɪᴄ, ɢᴜɪᴛᴀʀᴘʀɪɴᴄᴇꜱꜱ, ᴠᴀɢɢɪᴀʟᴀꜱᴛᴏʀ, ᴠᴀɢɢɪ x ᴍᴀɴ, ᴠᴇʟᴠᴇᴛᴛᴇ x ᴍᴀɴ, ʀᴀᴅɪᴏᴀᴘᴘʟᴇ (ᴜɴʟᴇꜱꜱ Qᴘʀ ᴏʀ ꜰʀɪᴇɴᴅꜱ), ʀᴀᴅɪᴏᴊᴏʏ, ꜱᴛᴀᴛɪᴄᴅᴜꜱᴛ, ʜᴏʟʏʙʟᴀᴅᴇꜱ (ᴜɴʟᴇꜱꜱ ɴᴏɴ-ʀᴏᴍᴀɴᴛɪᴄ), ʜᴏʟʏɢᴀᴛᴇꜱ, ᴍᴏᴛʜꜱʜᴇᴇᴘ, ꜱᴛᴀᴛɪᴄꜱʜᴇᴇᴘ, ɢᴜɪᴛᴀʀʜᴀʟᴏ, ʟᴜᴄɪꜰᴇʀ x ᴄʜᴀʀʟɪᴇ, ʟɪʟɪᴛʜ x ᴄʜᴀʀʟɪᴇ, ꜱᴇʀᴀ x ᴍᴀɴ, ꜱᴇʀᴀ x ᴇᴍɪʟʏ, ꜱᴛᴀᴛɪᴄʜᴀʟᴏ, ꜱᴛᴀᴛɪᴄɢᴜɪᴛᴀʀ.  

📺 : ɪᴡᴄ ⟢ ᴀᴅᴀᴍꜱᴀᴘᴘʟᴇ, ᴀᴘᴘʟᴇᴍᴇᴅɪᴀ, ᴍᴜʀᴅᴇʀᴍᴇᴅɪᴀ ( ɪꜰ ʏᴏᴜ ᴅᴏɴ'ᴛ ꜱᴇxᴜᴀʟɪᴢᴇ ɪɴᴛ! ), ɢᴜɪᴛᴀʀꜱᴘᴇᴀʀ, ᴀᴘᴘʟᴇꜱɴᴀᴋᴇ (ᴊᴜꜱᴛ ɴᴏᴛ ᴍʏ ꜰᴀᴠ!), ᴀɴɢᴇʟɪᴄʀᴀᴅɪᴏ/ʀᴀᴅɪᴏɢᴜɪᴛᴀʀ, ꜱᴛᴀᴛɪᴄꜱɪʟᴇɴᴄᴇ, ꜱᴘᴀʀᴋꜱᴅᴜᴏ.

## 👑 : " ʜᴇʟʟᴜᴠᴀ ʙᴏꜱꜱ "
___________

🐏 : ɪɴᴛ ⟢ ꜱᴛᴇʟʟᴀ x ʙᴀʀʙɪᴇ, ʙᴀʀʙɪᴇ x ᴠᴇʀᴏꜱɪᴋᴀ, ꜱᴇᴅᴜᴄᴛɪᴠᴇꜱᴍᴏᴋᴇ ( ᴠᴇʀᴏꜱɪᴋᴀ x ᴠᴀʟ ), ꜱᴛᴀᴛɪᴄʙᴇᴇ, ʙᴀʀʙᴠᴇʟ, ꜱᴛᴀᴛɪᴄᴘᴏᴘ, ꜰɪᴢᴢᴍᴏᴅᴇᴜꜱ, ʙᴀʀɴᴏᴡʟ, ꜱᴀʟʟɪᴇᴍᴀʏᴅᴀʏ, ꜰᴇᴀᴛʜᴇʀᴘᴏᴘ, ᴍᴀʀᴛʜʙᴇʀʀʏ, ʙᴇᴇ x ᴛᴇx, ʜᴏɴᴇʏᴍᴏᴏɴ, ꜱᴛᴇʟʟᴏꜱɪᴋᴀ, ꜱᴀʟʟɢɢɪ, ꜱᴡᴀɴᴍᴏᴛʜ ( ꜱᴛᴇʟʟᴀ x ᴠᴀʟ ), ᴏᴡʟᴍᴏᴛʜ, ꜱᴡᴀɴʙᴇᴇ.  

🌈 : ᴅɴɪ ⟢ ꜱᴛᴏʟɪᴛᴢ, ᴠᴇʀᴏʙʟɪᴛᴢ, ᴠᴇʀᴏꜱɪᴋᴀ x ᴛᴇx, ꜱᴛᴏʟᴀꜱ x ꜱᴛᴇʟʟᴀ, ᴍᴀᴍᴍᴏɴ x ꜰɪᴢᴢ, ʙᴇᴇ x ᴏᴢᴢɪᴇ, ᴄʜᴀᴢ x ʙʟɪᴛᴢ, ᴄʜᴀᴢ x ᴍɪʟʟɪᴇ, ᴄʜᴀᴢ x ᴍᴏxxɪᴇ, ʀᴀɪɴʙᴏᴡʜᴏʀɴꜱ (ʙʟɪᴛᴢ x ᴄʜᴀʀʟɪᴇ).

📺 : ɪᴡᴄ ⟢ ꜱᴛᴇʟʟᴀ x ꜱᴛʀɪᴋᴇʀ, ᴍᴀᴍᴍᴏɴ x ɢʟɪᴛᴢ & ɢʟᴀᴍ, ᴛᴇx x ʟᴏᴏɴᴀ, ꜱᴛᴀᴛɪᴄꜱʜᴀʀᴋ, ꜱᴛᴀᴛɪᴄʜᴏʀɴꜱ, ᴏᴢᴢɪᴇ x ᴠᴀʟ, ᴠᴀꜱꜱᴀʟᴘʜᴜꜱ, ꜱᴛᴏʟᴀɢᴏ, ꜱᴛᴏʟᴀɴᴅʀᴇ , ʙʟɪᴛᴢꜰɪᴢᴢ.
